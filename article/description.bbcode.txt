[size=5][b]Quick Product Manager – Fast AJAX Product & Category Manager for OpenCart 3[/b][/size]

[b]Stop opening a new page for every product. Find, filter, edit and add products and categories from one screen.[/b]

Quick Product Manager replaces the default OpenCart product and category lists with a fast, AJAX-based manager. Search, filter, edit and bulk-update your catalog without page reloads, then jump to the full OpenCart form only when you need it.

[size=4][b]Why you'll like it[/b][/size]

[list]
[*][b]One screen for the whole catalog.[/b] The list, the filters and the editor live together. Click a row and the editor opens in a side drawer.
[*][b]Edit only what changed.[/b] Only the tabs you touched are sent to the server, and one Save button saves them all. A dot marks unsaved tabs.
[*][b]Safe by design.[/b] Saving goes through the standard OpenCart models, so your existing extensions and permissions keep working. No extra permission setup.
[*][b]Easy to switch off.[/b] Disable the module and the default OpenCart lists come back at once. The classic list is also always available with one click.
[/list]

[size=4][b]Product Manager[/b][/size]

[list]
[*]Search by name or model, filter by status, choose the page size.
[*]Collapsible filters: category (with subcategories), manufacturer, model, store, SKU, UPC, EAN, JAN, ISBN, MPN and Requires Shipping.
[*]Active filters are shown as chips you can remove one by one.
[*]Sort by name or by date added.
[*]Edit the SEO URL right in the list, generate it from the name, copy it or open it on your storefront.
[*]Toggle status per row.
[*]Choose which columns the list shows (Model, Categories, Manufacturer, Price, Quantity, Date added) in the settings.
[*]Bulk actions: Enable, Disable, add to category, set manufacturer, Clone, Delete.
[*][b]Quick Add:[/b] name, model, categories, manufacturer, image and status. Everything else gets safe defaults. Choose Save, Save & add another, or Save & edit.
[/list]

[size=4][b]Product editor[/b][/size]

The drawer follows the default product form: General, Data, Category Links, Related Products, Other Links, Attribute, Option, Discount, Special, Image, Reward Points, SEO and Design. You choose the tab order and which optional tabs are shown.

[list]
[*]Multi-language and multi-store: descriptions, SEO keywords and layouts.
[*]Rich text editor for descriptions.
[*]Image popover: select a file, drag and drop, download from a URL, or open the file manager.
[*]A "Full product form" button opens the default form for fields added by other extensions.
[/list]

[size=4][b]Category Manager[/b][/size]

[list]
[*]AJAX category list with the full path, SEO URL, product count and status toggle. Every column is sortable.
[*]Search, status filter, parent filter, bulk Enable, Disable, Move to parent, show or hide in the top menu.
[*]Editor drawer: General, Data, SEO and Design, including parent, sort order, columns, image, stores and filters.
[*][b]Display Name:[/b] a separate, per-language name shown to customers in menus, breadcrumbs and category pages, while the category name stays for admin use.
[*][b]Extra parents:[/b] show one category under several parents (works with the Multiple Parent Category extension).
[*]Quick Add for new categories.
[/list]

[size=4][b]Barcode Manager[/b][/size]

Generate a Code128 barcode from the Model or SKU in the product editor and download it as a PNG. Model and SKU are checked for uniqueness. You can also show the barcode on the product page of the default and Barik themes.

[size=4][b]Works with other extensions[/b][/size]

[list]
[*][b]Complete SEO:[/b] when it is active, SEO H1, H2, H3, Keyword, Image alt and Image title appear in the editors and are saved correctly.
[*][b]Multiple Parent Category:[/b] extra parents appear in the category editor.
[*][b]hpmm media manager:[/b] if it is installed, its image popover is used. Otherwise the built-in popover is used.
[/list]

[size=4][b]Installation[/b][/size]

[list=1]
[*]Extensions > Installer: upload the package.
[*]Extensions > Modifications: click Refresh.
[*]Extensions > Extensions > Modules: install Quick Product Manager.
[*]Click Edit, set Status to Enabled and save.
[/list]

[size=4][b]FAQ[/b][/size]

[b]Will it change my products?[/b]
Only when you save an edit. The module reads and writes through the standard OpenCart models.

[b]Can I still use the original product form?[/b]
Yes. Use the "Full product form" button, or open the classic list with one click.

[b]What if I uninstall it?[/b]
Your catalog is untouched. Only the Display Name table is kept, in case you reinstall.

[b]Does it support more than one language or store?[/b]
Yes, in descriptions, SEO URLs and layouts.
